# Results

- `latest.csv` gives the main cycles-per-second results.
- `latest.json` gives the same results with commands and timing samples.
- `comparison.csv` compares the same Boolean circuit on upstream GEM and this project.
- `carry4_optimization.json` contains the CARRY4 timing samples made by
  `benchmark_carry4.py`.

New local runs are first stored in `benchmark/temporary/`.
